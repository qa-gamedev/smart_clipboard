# Smart Clipboard Manager — Умный буфер обмена + OCR & Переводчик

Продвинутый менеджер буфера обмена для Windows с поддержкой распознавания текста (OCR), локального и онлайн-перевода, экранного оверлея и изоляции секретных данных.

---

## 🔑 Ключевые возможности

### 📋 Умная история буфера обмена (`Alt+V`)

* **Категоризация и фильтрация:** разделение на Текст, Ссылки, Изображения, Избранное и Заметки.
* **Умный поиск:** поиск не только по тексту, но и по содержимому сохраненных скриншотов (благодаря фоновому OCR).
* **Быстрые действия:** моментальная генерация QR-кода для любого элемента, копирование, очистка форматирования (Plain text), закрепление сверху.
* **Синхронизация:** возможность подтягивать системную историю Windows (`Win+V`) при запуске.

### 🔍 Сканер экрана и OCR (`Alt+S`)

* **Захват области:** выделение любого фрагмента экрана для моментального распознавания текста и QR/штрихкодов.
* **Движки распознавания:**
* **Windows OCR** — встроенный быстрый движок (без скачивания дополнительных компонентов).
* **Tesseract OCR** — для сложной верстки и специфических языков.
* **OCR.space** — онлайн-резерв.
* **zxing-cpp** — автоматическое декодирование QR и штрихкодов.



### 🌐 Переводчик поверх экрана (`Alt+T`)

* **Экранный оверлей:** накладывает перевод прямо поверх текста на экране в режиме реального времени (поддерживает как выделенную область, так и весь экран).
* **Офлайн-перевод (NLLB-200):** полноценная работа без интернета и блокировок через `ctranslate2` (200 языков).
* **Онлайн-перевод:** поддержка Google Translate, Argos Translate и автоматическая конвертация валют.

### 🔒 Секретный режим (`Alt+Shift+V`)

* **Изолированное хранилище:** секретная база данных и медиафайлы сохраняются в отдельную скрытую папку.
* **Защита PIN-кодом:** вход по паролю (хешируется, не хранится в открытом виде).
* **Автовыход:** автоматическая блокировка и очистка кэша перевода при бездействии.
* **Визуальный индикатор:** фиолетовая рамка и метка в трее сигнализируют об активном секретном режиме.

## ⌨️ Горячие клавиши по умолчанию

| Комбинация | Действие |
| --- | --- |
| `Alt + V` | Открыть/скрыть окнo истории |
| `Alt + S` | Сканер экрана (OCR и перевод) |
| `Alt + T` | Перевод поверх экрана (выделение области) |
| `Alt + Shift + V` | Переключение секретного режима |
| `Alt + N` | Создать новую заметку |

## 🛠 Системные требования и зависимости

* **ОС:** Windows 10 (1803+) / Windows 11 (64-bit)
* **Python:** 3.10 – 3.13

### Основные библиотеки:

* `PyQt6` — графический интерфейс
* `winrt-Windows.*` — интеграция с Windows OCR и системным буфером
* `qrcode`, `zxing-cpp` — генерация и сканирование QR-кодов
* `ctranslate2`, `sentencepiece` — офлайн-перевод NLLB-200
* `deep-translator`, `requests` — онлайн-перевод

---

## 🚀 Быстрый запуск

### 1. Установка зависимостей

```bash
pip install PyQt6 qrcode deep-translator requests winrt-runtime winrt-Windows.Foundation winrt-Windows.Foundation.Collections winrt-Windows.Globalization winrt-Windows.Graphics.Imaging winrt-Windows.Media.Ocr winrt-Windows.Storage.Streams winrt-Windows.ApplicationModel.DataTransfer ctranslate2 sentencepiece zxing-cpp numpy

```

### 2. Запуск приложения

Запуск в фоновом режиме (без окна консоли Windows):

```bash
pythonw main.py

```

### 3. Загрузка офлайн-модели перевода (опционально)

Для работы перевода без интернета скачайте модель NLLB-200 (~630 МБ) через меню **Настройки → Распознавание и перевод** или выполните скрипт:

```bash
python install_model.py

```
